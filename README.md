# Game Shelf

A colourful, dependency-free collection of small browser games, ready for GitHub Pages.

## Games

- Neon Snake, Space Dodger, Memory Match, Reaction Test, Word Guess, Clicker Adventure, Sky Flyer, Mini Platformer, and Tic-Tac-Toe
- Checkers with easy, medium, and hard computer opponents
- City Trader, an original property-trading board game

## Play locally

Open `index.html` in a modern browser. No build step or package installation is needed.

City Trader is original and is not affiliated with or branded as Monopoly.
